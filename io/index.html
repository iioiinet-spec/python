01강 입출력문 인터랙티브 강의

print() · input() · 형변환 · 입력 패턴 — 그리고 직접 풀어보는 연습문제 15제
OUTPUTprint() — 화면에 결과 보여주기
입력(Input)은 키보드로 값을 넣는 것, 출력(Output)은 프로그램이 화면에 결과를 보여주는 것입니다.

01print() 여섯 가지 사용법

print("Hello Python")      # ① 기본 출력 → Hello Python
print("나이:", 13)          # ② 여러 값 → 나이: 13

name = "민수"
print(name)                 # ③ 변수 출력 → 민수

a = 3
b = 5
print(a, b)                 # ④ 여러 변수 → 3 5

print(1, 2, 3, sep="-")     # ⑤ sep: 구분자 → 1-2-3

print("Hello", end=" ")     # ⑥ end: 줄바꿈 변경
print("Python")             #    → Hello Python (한 줄!)

02sep 실험실 — 구분자를 바꿔보세요

INTERACTIVE · print(값들, sep="?")

03end 실험실 — 줄바꿈을 바꿔보세요

print는 끝에 자동으로 줄바꿈(\n)을 붙입니다. end 옵션으로 바꿀 수 있어요.

INTERACTIVE · print("Hello", end="?") 다음 print("Python")
INPUTinput() — 키보드로 값 받기
input()은 무엇을 입력해도 항상 문자열(str)로 받습니다. 숫자로 쓰려면 int()로 바꿔야 해요!

01input() 네 가지 사용법

name = input()                    # ① 문자열 입력
name = input("이름을 입력하세요: ")   # ② 안내문과 함께
a = int(input())                  # ③ 정수 입력 (형변환!)
a, b = map(int, input().split())  # ④ 두 숫자 한 줄 입력

02"7"과 7은 다르다! — 자료형 비교 실험

같은 값을 입력해도 int()를 쓰느냐에 따라 a + a의 결과가 완전히 달라집니다.

INTERACTIVE · 입력값을 넣고 두 버튼을 비교해 보세요
버튼을 눌러 a + a 결과를 확인하세요.

03map 분해기 — a, b = map(int, input().split())

한 줄이지만 4단계가 숨어 있습니다. 각 단계에서 값이 어떻게 변하는지 보세요.
