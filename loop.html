💡 반복문이란?

반복문은 같은 코드를 여러 번 반복해서 실행할 때 사용하는 문법입니다.

📌 핵심 구조

for 변수 in range(반복횟수): 형태로 사용합니다.
들여쓰기(4칸) 안의 코드가 반복 실행됩니다.

예제 1 0~4 출력 (5회 반복)
for i in range(5):
    print(i)
0 1 2 3 4
예제 2 1~5 출력
for i in range(1, 6):
    print(i)
1 2 3 4 5
예제 3 "Hello" 5번 출력
for i in range(5):
    print("Hello")
Hello Hello Hello Hello Hello
예제 4 1~10 합 구하기
total = 0

for i in range(1, 11):
    total += i

print(total)
55

🔄 while 문

📌 핵심 개념

조건이 참(True)인 동안 계속 반복합니다.
반드시 반복 변수를 직접 증가시켜야 무한 루프를 방지할 수 있습니다.

예제 1 1~5 출력
i = 1

while i <= 5:
    print(i)
    i += 1   # 반드시 증가!
1 2 3 4 5
예제 2 Hello 3번 출력
i = 0

while i < 3:
    print("Hello")
    i += 1
Hello Hello Hello
예제 3 1~10 합 (while)
i = 1
s = 0

while i <= 10:
    s += i
    i += 1

print(s)
55

⛔ break 문

📌 break

break는 반복문을 강제로 종료합니다. 조건을 만족하면 즉시 루프를 빠져나옵니다.

break i가 5가 되면 종료
for i in range(10):
    if i == 5:
        break        # 여기서 종료!
    print(i)
0 1 2 3 4
⏭️ continue 문

📌 continue

continue는 현재 반복을 건너뛰고 다음 반복으로 이동합니다. 루프 자체는 계속됩니다.

continue i가 3이면 건너뜀
for i in range(1, 6):
    if i == 3:
        continue     # 3 건너뜀
    print(i)
1 2 4 5
📊 break vs continue 비교
구문동작루프 상태
break즉시 루프 탈출종료
continue현재 반복만 건너뜀계속

🔩 중첩 반복문

📌 중첩 반복문

반복문 안에 반복문을 넣을 수 있습니다. 바깥 루프 1회마다 안쪽 루프 전체가 실행됩니다.

중첩 i, j 쌍 출력
for i in range(3):
    for j in range(3):
        print(i, j)
0 0 / 0 1 / 0 2 1 0 / 1 1 / 1 2 2 0 / 2 1 / 2 2
⭐ 별찍기 예제
별 5줄 출력
for i in range(5):
    print("*")
* * * * *
별 삼각형
for i in range(1, 6):
    print("*" * i)
* ** *** **** *****
🔢 구구단 · 리스트 순회
구구단 2단
for i in range(1, 10):
    print("2 x", i, "=", 2*i)
2 x 1 = 2 2 x 2 = 4 2 x 3 = 6 ...
리스트 순회
arr = [10, 20, 30, 40]

for x in arr:
    print(x)
10 20 30 40
enumerate 인덱스 + 값
arr = ["a", "b", "c"]

for i, v in enumerate(arr):
    print(i, v)
0 a 1 b 2 c
