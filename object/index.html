💡 객체(Object)란?

객체는 데이터 + 기능(함수)를 함께 가진 것입니다.
현실 세계의 사물을 코드로 표현하는 방법입니다.

🎓 학생 → 이름·점수 + 공부하기 기능
🚗 자동차 → 색깔·속도 + 달리기 기능

클래스(설계도) → 객체(실제 사용) 관계

__init__ 생성자 (가장 중요!)
class Student:
    def __init__(self, name, score):
        self.name  = name    # 속성 저장
        self.score = score

s1 = Student("민수", 90)
print(s1.name)
print(s1.score)
민수 90

📌 self 이해하기

self는 자기 자신 객체를 가리킵니다.
self.name은 "이 객체의 name"이라는 뜻입니다.
모든 메서드의 첫 번째 인자로 반드시 넣어야 합니다.

📌 메서드란?

클래스 안에 정의된 함수를 메서드라고 합니다.
항상 첫 번째 인자는 self입니다.
호출할 때는 객체.메서드() 형태로 사용합니다.

메서드 say_hello 메서드
class Student:
    def __init__(self, name):
        self.name = name

    def say_hello(self):
        print("안녕 나는", self.name)

s1 = Student("민수")
s1.say_hello()    # 객체.메서드() 형태
안녕 나는 민수
반환값 return 있는 메서드
class Student:
    def __init__(self, score):
        self.score = score

    def grade(self):
        if self.score >= 90:
            return "A"
        else:
            return "B"

s = Student(95)
print(s.grade())
A
❌ 자주 하는 실수 self 빠뜨리기
# ❌ 잘못된 예
def show():         # self 없음 → 오류!
    print(self.name)

# ✅ 올바른 예
def show(self):      # self 필수!
    print(self.name)
메서드의 첫 번째 인자는 반드시 self를 써야 합니다!
🔗 클래스 활용
여러 객체 하나의 클래스로 여러 객체 생성
class Student:
    def __init__(self, name, score):
        self.name  = name
        self.score = score

    def show(self):
        print(self.name, self.score)

s1 = Student("민수", 90)
s2 = Student("지아", 85)

s1.show()
s2.show()
민수 90 지아 85
리스트 객체를 리스트로 관리
students = [
    Student("민수", 90),
    Student("지아", 85),
    Student("철수", 88)
]

for s in students:
    s.show()
민수 90 지아 85 철수 88
반복문 클래스 내 반복문 활용
class Numbers:
    def __init__(self, arr):
        self.arr = arr

    def total(self):
        s = 0
        for x in self.arr:
            s += x
        return s

n = Numbers([1, 2, 3, 4])
print(n.total())
10

예제 1 학생 클래스
class Student:
    def __init__(self, name, score):
        self.name  = name
        self.score = score

    def show(self):
        print("이름:", self.name)
        print("점수:", self.score)

s1 = Student("민수", 90)
s1.show()
이름: 민수 점수: 90
예제 2 계산기 클래스
class Calculator:
    def __init__(self, a, b):
        self.a = a
        self.b = b

    def add(self):
        return self.a + self.b

    def mul(self):
        return self.a * self.b

c = Calculator(3, 4)
print(c.add())
print(c.mul())
7 12
예제 3 자동차 클래스
class Car:
    def __init__(self, color, speed):
        self.color = color
        self.speed = speed

    def drive(self):
        print(self.color, "자동차가", self.speed, "속도로 달립니다")

c1 = Car("빨간색", 100)
c1.drive()
빨간색 자동차가 100 속도로 달립니다
