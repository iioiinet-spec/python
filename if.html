조건문이란?

조건문은 어떤 조건이 참(True)일 때만 실행되는 문장입니다.
예를 들어 "나이가 14세 이상이면 중학생입니다"처럼, 조건에 따라 다른 코드를 실행할 수 있습니다.

📐 기본 구조
if 기본 if 구조
if 조건:
    실행할 코드  # 들여쓰기(4칸) 필수!
예제 나이로 학생 구분
age = 15

if age >= 14:
    print("중학생입니다")
중학생입니다

Flow if 문 실행 흐름
시작 (START)
↓
조건 판단

↓

↓

↓
종료 (END)
🔀 if - else 문

📌 핵심 개념

조건이 참(True)이면 if 블록이 실행되고, 거짓(False)이면 else 블록이 실행됩니다.

ifelse 짝수 / 홀수 판별
n = int(input())

if n % 2 == 0:
    print("짝수")
else:
    print("홀수")
입력 4 → 짝수
입력 7 → 홀수
ifelse 양수 / 음수 판별
n = int(input())

if n > 0:
    print("양수입니다")
else:
    print("양수가 아닙니다")
입력 5 → 양수입니다
ifelse 합격 / 불합격
score = int(input())

if score >= 60:
    print("합격")
else:
    print("불합격")
입력 75 → 합격
입력 40 → 불합격
🔢 if - elif - else 문

📌 핵심 개념

여러 조건을 순서대로 검사할 때 사용합니다.
위에서부터 순서대로 조건을 확인하고, 처음으로 참이 되는 블록만 실행됩니다.

ifelifelse 성적 등급
score = int(input())

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")
입력 95 → A    입력 82 → B    입력 70 → C
elif 양수 / 0 / 음수 구분
n = int(input())

if n > 0:
    print("양수")
elif n == 0:
    print("ZERO")
else:
    print("음수")
입력 5 → 양수    입력 0 → ZERO    입력 -3 → 음수
⚡ 비교 연산자
연산자의미예시
>크다a > 5 → a가 5보다 크면 True
<작다a < 10 → a가 10보다 작으면 True
>=크거나 같다a >= 0 → a가 0 이상이면 True
<=작거나 같다a <= 100 → a가 100 이하이면 True
==같다a == b → a와 b가 같으면 True
!=다르다a != b → a와 b가 다르면 True
🔗 논리 연산자
연산자의미설명
and그리고두 조건이 모두 참일 때 True
or또는두 조건 중 하나라도 참이면 True
not부정참이면 False, 거짓이면 True
and / or 논리 연산자 예제
age = 15

# and: 두 조건 모두 참
if age >= 14 and age <= 16:
    print("중학생")

# or: 하나만 참이어도 실행
if age == 13 or age == 15:
    print("특정 나이")
중학생
특정 나이
🔩 중첩 if 문

📌 중첩 if

조건문 안에 또 다른 조건문을 넣을 수 있습니다. 들여쓰기로 계층을 구분합니다.

중첩 양수이면서 짝수인지 판별
n = int(input())

if n > 0:           # 바깥 조건: 양수
    if n % 2 == 0:  # 안쪽 조건: 짝수
        print("양수 짝수")
입력 4 → 양수 짝수
입력 3 → (출력 없음)
⚡ 삼항 연산 (한 줄 if)

📌 삼항 연산자

간단한 if-else를 한 줄로 표현하는 방법입니다.

삼항 짝수/홀수 한 줄 표현
# 일반 방식
n = int(input())
if n % 2 == 0:
    print("짝수")
else:
    print("홀수")

# 삼항 연산으로 한 줄
print("짝수" if n % 2 == 0 else "홀수")
입력 6 → 짝수
