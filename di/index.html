📈 선 그래프 (Line Chart)

언제 쓸까?

시간이 지남에 따라 값이 어떻게 변하는지 보여줄 때 사용합니다.
예: 시험 점수 변화, 게임 점수 변화, 일별 공부 시간 변화

기본 가장 기본적인 선 그래프
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [2, 4, 6, 8, 10]

plt.plot(x, y)
plt.show()
→ 선 그래프 화면에 표시
옵션 제목과 축 이름 추가
import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y = [10, 15, 13, 20]

plt.plot(x, y)
plt.title("Score Graph")   # 제목
plt.xlabel("Day")          # x축 이름
plt.ylabel("Score")        # y축 이름
plt.show()
예제 시험 점수 변화 그래프
import matplotlib.pyplot as plt

test_num = [1, 2, 3, 4, 5]
scores   = [60, 70, 75, 85, 90]

plt.plot(test_num, scores)
plt.title("Test Score Change")
plt.xlabel("Test Number")
plt.ylabel("Score")
plt.show()
시험 1~5회 점수: 60→70→75→85→90 (점수 상승 추이 확인)
📊 막대 그래프 (Bar Chart)

언제 쓸까?

여러 항목을 한눈에 비교할 때 사용합니다.
예: 과목별 점수 비교, 학생별 성적, 월별 매출 비교

기본 막대 그래프
import matplotlib.pyplot as plt

name  = ["A", "B", "C"]
score = [80, 90, 75]

plt.bar(name, score)
plt.show()
A=80, B=90, C=75 막대 그래프 출력
예제 과목별 점수 막대 그래프
import matplotlib.pyplot as plt

subjects = ["Math", "Science", "English", "Coding"]
scores   = [85, 90, 80, 95]

plt.bar(subjects, scores)
plt.title("Subject Scores")
plt.xlabel("Subject")
plt.ylabel("Score")
plt.show()
Math=85, Science=90, English=80, Coding=95
원 그래프 (Pie Chart)

언제 쓸까?

전체 중에서 각 항목의 비율을 보여줄 때 사용합니다.
예: 좋아하는 과목 비율, 하루 시간 사용 비율, 취미 활동 비율

기본 원 그래프
import matplotlib.pyplot as plt

labels = ["Python", "Game", "AI"]
sizes  = [40, 35, 25]

plt.pie(sizes, labels=labels)
plt.show()
Python 40%, Game 35%, AI 25% 원형 비율 출력
예제 취미 비율 원 그래프
import matplotlib.pyplot as plt

labels = ["Game", "Reading", "Sports", "Coding"]
sizes  = [30, 20, 25, 25]

plt.pie(sizes, labels=labels)
plt.title("Hobby Ratio")
plt.show()
Game 30% / Reading 20% / Sports 25% / Coding 25%

막대 그래프plt.bar()항목 간 비교과목별 점수, 국가별 인구
원 그래프plt.pie()전체 비율 표시취미 비율, 시간 배분
이미지 처리 (Pillow)

Pillow란?

Python으로 이미지를 다룰 수 있게 해주는 라이브러리입니다.
열기·크기변경·회전·잘라내기·저장이 가능합니다.

열기 이미지 열고 보기
from PIL import Image

img = Image.open("sample.jpg")
print(img.size)   # (800, 600) 형태
img.show()
(800, 600)
resize 크기 변경
from PIL import Image

img = Image.open("sample.jpg")
small = img.resize((300, 200))
small.show()
300×200으로 축소 후 표시
rotate 이미지 회전
from PIL import Image

img = Image.open("sample.jpg")
rot = img.rotate(90)
rot.show()
90도 회전 후 표시
crop 이미지 잘라내기
from PIL import Image

img = Image.open("sample.jpg")
# (왼쪽, 위, 오른쪽, 아래)
cut = img.crop((100, 100, 300, 300))
cut.show()
200×200 구간 잘라서 표시
save 저장하기
from PIL import Image

img = Image.open("sample.jpg")
small = img.resize((200, 200))
small.save("new_image.jpg")
# 원본 보존, 새 파일 저장
new_image.jpg 파일 생성 완료
