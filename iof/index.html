1. Python 입력의 기본 구조

핵심: input()으로 받은 값은 기본적으로 문자열(str)입니다.

예제 1. 문자열 한 줄 입력

name = input()
print(name)

예제 2. 정수 하나 입력

age = int(input())
print(age)

예제 3. 실수 하나 입력

x = float(input())
print(x)

2. split()의 기본 개념

split()은 문자열을 일정한 기준으로 나누어 리스트로 만들어 줍니다.

문자열.split() → 공백을 기준으로 나눔
문자열.split("구분자") → 지정한 구분자로 나눔
예제 1. 공백으로 단어 나누기
s = "Python is easy"
a = s.split()

print(a)
결과
['Python', 'is', 'easy']
포인트
split()은 결과를 리스트로 반환
예제 2. 입력받은 두 문자열 나누기
a, b = input().split()

print(a)
print(b)
입력
apple banana
출력
apple
banana
예제 3. 정수 두 개 입력
a, b = input().split()

a = int(a)
b = int(b)

print(a + b)
입력
10 20
출력
30

3. split() + map()의 가장 중요한 패턴

코딩 문제에서 가장 자주 사용하는 형태입니다.

a, b = map(int, input().split())

동작 순서는 다음과 같습니다.

  1. input() : 한 줄을 문자열로 입력받음
  2. split() : 공백 기준으로 나눔
  3. map(int, ...) : 각 값을 정수로 변환
  4. a, b = ... : 두 변수에 각각 저장
예제 4. 두 수의 합
a, b = map(int, input().split())
print(a + b)
예제 5. 세 정수 입력
a, b, c = map(int, input().split())
print(a + b + c)
예제 6. 여러 정수를 리스트로 받기
nums = list(map(int, input().split()))

print(nums)
print(sum(nums))
입력
3 8 2 9 5
출력
[3, 8, 2, 9, 5]
27

4. split()의 다양한 구분자 사용

코드의미예시
split()공백 기준"10 20 30"
split(",")쉼표 기준"red,green,blue"
split("-")하이픈 기준"2026-09-11"
split(":")콜론 기준"15:30:20"
split("/")슬래시 기준"2026/09/11"
예제 7. 쉼표로 나누기
colors = "red,green,blue"
a = colors.split(",")

print(a)
출력
['red', 'green', 'blue']
활용
CSV 형태의 간단한 데이터 처리
예제 8. 날짜 나누기
year, month, day = input().split("-")

print(year)
print(month)
print(day)
입력
2026-09-11
출력
2026
09
11
예제 9. 시간 나누기
h, m, s = map(int, input().split(":"))

print(h)
print(m)
print(s)
입력
14:35:50
출력
14
35
50
예제 10. split() 최대 분할 횟수 지정
s = "one two three four"
a = s.split(" ", 2)

print(a)
출력
['one', 'two', 'three four']
설명
두 번까지만 나누고 나머지는 하나로 유지
알아두기: 인자 없이 사용하는 split()은 연속된 공백을 자연스럽게 처리합니다. 
s = "10    20   30"
print(s.split())

# ['10', '20', '30']
주의: split(" ")은 정확히 한 칸의 공백을 구분자로 보기 때문에 연속 공백에서 빈 문자열이 생길 수 있습니다.

5. print()와 format() 기본

format()은 문자열 안의 {} 자리에 값을 넣어 출력하는 방법입니다.

예제 11. 기본 format()
name = "Kim"
age = 20

print("이름: {}, 나이: {}".format(name, age))
출력
이름: Kim, 나이: 20
핵심
{} 순서대로 값이 들어감
예제 12. 번호로 위치 지정
print("{0} + {1} = {2}".format(10, 20, 30))
print("{1} {0} {1}".format("A", "B"))

# B A B
예제 13. 이름을 지정하여 출력
print("이름: {name}, 점수: {score}".format(
    name="Mina",
    score=95
))

6. format() 정렬과 출력 폭

표현의미
{:<10}10칸 확보 후 왼쪽 정렬
{:>10}10칸 확보 후 오른쪽 정렬
{:^10}10칸 확보 후 가운데 정렬
예제 14. 정렬 비교
word = "Python"

print("|{:<10}|".format(word))
print("|{:>10}|".format(word))
print("|{:^10}|".format(word))
|Python    |
|    Python|
|  Python  |
예제 15. 빈칸 대신 문자 채우기
print("{:*^20}".format("Python"))
출력
*******Python*******
설명
*로 채우고 가운데 정렬

문제 10. 종합 문제

입력
Keyboard 58000 0.15
출력 예

정답

price = int(price)
rate = float(rate)

final_price = int(price * (1 - rate))

print("{} : {:,}원".format(name, final_price))
