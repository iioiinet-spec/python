💡 입출력이란?

파이썬에서 입력(Input)은 사용자가 키보드로 값을 넣는 것이고, 출력(Output)은 프로그램이 화면에 결과를 보여주는 것입니다.

프로그램은 입력을 받아 → 처리하고 → 결과를 출력하는 흐름으로 동작합니다.

⌨️
사용자 → 프로그램
input()
🖥️
프로그램 → 화면
print()
기본 흐름 입출력 프로그램 구조
# 1. 입력받기 name = input("이름을 입력하세요: ") # 2. 처리하기 greeting = "안녕하세요, " + name # 3. 출력하기 print(greeting)
안녕하세요, 민수
🖨️ print() 출력문 예시
예시 1 기본 출력
print("Hello Python")
Hello Python
예시 2 여러 값 출력
print("나이:", 13)
나이: 13
예시 3 변수 출력
name = "민수" print(name)
민수
예시 4 여러 변수 한번에 출력
a = 3 b = 5 print(a, b)
3 5
예시 5 sep 옵션 — 구분자 변경
print(1, 2, 3, sep="-")
1-2-3
예시 6 end 옵션 — 줄바꿈 변경
print("Hello", end=" ") print("Python")
Hello Python
⌨️ input() 입력문 예시
예시 1 문자열 입력
name = input() print(name)
민수
예시 2 안내문과 함께 입력
name = input("이름을 입력하세요: ") print(name)
이름을 입력하세요: 민수 민수
예시 3 정수 입력 — int() 변환
# input()은 기본적으로 문자열! # 숫자로 쓰려면 int()로 변환 a = int(input()) print(a)
7
예시 4 두 숫자 입력 — map + split
a, b = map(int, input().split()) print(a + b)
3 5 입력 시 → 8
⚡ 자주 사용하는 입력 패턴
패턴
설명
n = int(input())
정수 1개 입력
s = input()
문자열 입력
a, b = map(int, input().split())
정수 여러 개 입력 (공백 구분)
arr = list(map(int, input().split()))
정수 리스트로 입력
종합 네 가지 패턴 한눈에 보기
# 1. 정수 1개 n = int(input()) print(n) # 2. 문자열 s = input() print(s) # 3. 정수 여러 개 a, b = map(int, input().split()) print(a, b) # 4. 리스트 arr = list(map(int, input().split())) print(arr)
