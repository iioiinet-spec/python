💡 문자열이란?

문자열은 글자들의 모음입니다. "apple", "Hello", "123" 모두 문자열입니다.
파이썬에서는 ' ' 또는 " "로 묶어서 만듭니다.

✅ 순서 있음  |  ✅ 인덱스로 접근 가능  |  ❌ 수정 불가 (immutable)

🔬 문자열 구조 시각화
문자열을 입력하면 인덱스 구조를 시각화합니다 (셀 클릭 → 상세 정보)
👆 셀을 클릭해보세요

print(type(c))
<class 'str'>
주의 수정 불가 (immutable)
s = "apple"
# s[0] = "A"  → 오류!

# 새 문자열을 만들어야 함
s = "A" + s[1:]
print(s)

🎯 인덱싱 (Indexing)

음수 뒤에서 인덱싱

✂️ 슬라이싱 (Slicing)
슬라이싱 s[start:end] — end는 미포함
s = "python"
print(s[0:2])   # py
print(s[2:5])   # tho
print(s[:3])    # pyt
print(s[3:])    # hon
print(s[::-1])  # nohtyp (뒤집기!)
py tho pyt hon nohtyp
len 문자열 길이

🔤 ord() / chr()
ord() 문자 → 숫자
print(ord("A"))   # 65
print(ord("a"))   # 97
print(ord("0"))   # 48
65 97 48
chr() 숫자 → 문자
print(chr(65))   # A
print(chr(97))   # a
print(chr(48))   # 0
A a 0
⚙️ 문자열 메서드 ① — 변환·탐색
upper() 대문자
print("hello".upper())
HELLO
lower() 소문자
print("HELLO".lower())
hello
title() 단어 첫 글자 대문자
print("hello python".title())
Hello Python
capitalize() 첫 글자만
print("hello python".capitalize())
Hello python
strip() 공백 제거
s = "   hello   "
print(s.strip())
print(s.lstrip())
print(s.rstrip())
hello hello hello
replace(a,b) 치환
s = "I like apple"
print(s.replace("apple", "banana"))
I like banana
find() 위치 찾기 (없으면 -1)
s = "banana"
print(s.find("a"))    # 1
print(s.find("na"))   # 2
print(s.find("z"))    # -1

count() 개수 세기
s = "banana"
print(s.count("a"))    # 3
print(s.count("na"))   # 2
3 2
split() 나누기
s = "red blue green"
print(s.split())
print("a,b,c".split(","))
['red', 'blue', 'green'] ['a', 'b', 'c']
join() 합치기
arr = ["red", "blue", "green"]
print(" ".join(arr))
print("-".join(arr))
red blue green red-blue-green
⚙️ 문자열 메서드 ② — 검사
startswith() 시작 검사
s = "python"
print(s.startswith("py"))   # True
print(s.startswith("th"))   # False
True False
endswith() 끝 검사
s = "python"
print(s.endswith("on"))   # True
print(s.endswith("py"))   # False
True False
isalpha() 모두 글자?
print("abc".isalpha())    # True
print("abc1".isalpha())   # False
True False
isdigit() 모두 숫자?
print("123".isdigit())    # True
print("12a".isdigit())   # False
True False
isalnum() 글자+숫자?
print("abc123".isalnum())    # True
print("abc123!".isalnum())   # False
True False
isspace() 공백만?
print("   ".isspace())   # True
print(" a ".isspace())   # False
True False

⚡ 자주 쓰는 패턴
패턴 1 특정 문자 세기
s = "banana"
cnt = 0
for ch in s:
    if ch == "a":
        cnt += 1
print(cnt)
3
패턴 2 모음 개수 세기
s = "apple"
cnt = 0
for ch in s:
    if ch in "aeiou":
        cnt += 1
print(cnt)
2
패턴 3 대문자만 세기
s = "AbCDxyZ"
cnt = 0
for ch in s:
    if "A" <= ch <= "Z":
        cnt += 1
print(cnt)
4
패턴 4 숫자만 추출
s = "a1b2c3"
result = ""
for ch in s:
    if ch.isdigit():
        result += ch
print(result)
123
