💡 딕셔너리란?

딕셔너리는 키(key)와 값(value)을 한 쌍으로 저장하는 자료형입니다.
리스트는 번호(index)로 찾지만, 딕셔너리는 키(key)로 찾습니다.

학생 이름→점수, 과일→가격처럼 짝을 이루는 데이터를 저장할 때 매우 유용합니다.

📋 리스트 vs 딕셔너리
구분리스트딕셔너리
생성[1, 2, 3]{"a":1, "b":2}
접근인덱스 (0,1,2…)키 (key)
순서있음삽입 순서 유지 (3.7+)
중복값 중복 가능키 중복 불가 (덮어씌움)
활용순서 있는 나열짝 데이터, 빈도수
🔑 값 꺼내기
d[key] 대괄호로 접근
d = {"apple": 3, "banana": 5}
print(d["apple"])   # 3
3
키가 없으면 오류(KeyError)!
get() 안전하게 접근
d = {"apple": 3}
print(d.get("apple"))    # 3
print(d.get("grape"))    # None
print(d.get("grape", 0))  # 0
3 None 0
✏️ 추가 · 수정
추가 없는 키 → 새로 추가
d = {}
d["name"] = "Jane"
print(d)
{'name': 'Jane'}
수정 있는 키 → 값 교체
d = {"score": 80}
d["score"] = 100
print(d)
{'score': 100}
🗑️ 삭제
del 키 삭제
d = {"a": 1, "b": 2}
del d["a"]
print(d)
{'b': 2}
pop() 삭제 + 값 반환
d = {"a": 1, "b": 2}
x = d.pop("a")
print(x)
print(d)
1 {'b': 2}

⚙️ 딕셔너리 메서드
keys() 키만 보기
d = {"name": "Tom", "age": 13}
print(list(d.keys()))
['name', 'age']
values() 값만 보기
d = {"name": "Tom", "age": 13}
print(list(d.values()))
['Tom', 13]
items() 키+값 쌍
d = {"name": "Tom", "age": 13}
print(list(d.items()))
[('name', 'Tom'), ('age', 13)]
update() 여러 개 추가/수정
d = {"a": 1, "b": 2}
d.update({"b": 20, "c": 30})
print(d)
{'a': 1, 'b': 20, 'c': 30}
setdefault() 없으면 기본값
d = {"a": 1}
d.setdefault("a", 100)  # 이미 있음 → 유지
d.setdefault("b", 200)  # 없음 → 추가
print(d)
{'a': 1, 'b': 200}
popitem() 마지막 쌍 꺼내기
d = {"a": 1, "b": 2}
print(d.popitem())
print(d)
('b', 2) {'a': 1}
copy() 복사
a = {"x": 1}
b = a.copy()
b["x"] = 999
print(a)  # 원본 변화 없음
print(b)
{'x': 1} {'x': 999}
clear() 전체 삭제
d = {"a": 1, "b": 2}
d.clear()
print(d)
{}

🔁 딕셔너리 반복문
방법 1 키만 반복
d = {"a": 10, "b": 20, "c": 30}

for key in d:
    print(key)
a b c
방법 2 키 + 값 함께
d = {"a": 10, "b": 20, "c": 30}

for key in d:
    print(key, d[key])
a 10 b 20 c 30
방법 3 items() 사용 — 가장 권장
d = {"a": 10, "b": 20, "c": 30}

for key, value in d.items():
    print(key, value)
a 10 b 20 c 30
🔤 정렬해서 출력
sorted 키 정렬 출력
d = {"banana": 3, "apple": 5, "cherry": 2}

for key in sorted(d.keys()):
    print(key, d[key])
apple 5 banana 3 cherry 2
⚡ 자주 쓰는 패턴
패턴 1 문자 등장 횟수 세기
s = "banana"
d = {}

for ch in s:
    d[ch] = d.get(ch, 0) + 1

print(d)
{'b': 1, 'a': 3, 'n': 2}
패턴 2 리스트 숫자 빈도수
arr = [1, 2, 2, 3, 1, 2]
d = {}

for x in arr:
    d[x] = d.get(x, 0) + 1

print(d)
{1: 2, 2: 3, 3: 1}
패턴 3 최빈값 찾기
arr = [1, 2, 2, 3, 3, 3, 4]
d = {}

for x in arr:
    d[x] = d.get(x, 0) + 1

mx_key, mx_cnt = None, 0
for k, v in d.items():
    if v > mx_cnt:
        mx_cnt = v
        mx_key = k

print(mx_key, mx_cnt)
3 3
패턴 4 리스트 안에 딕셔너리
students = [
    {"name": "Tom", "score": 80},
    {"name": "Jane", "score": 95},
    {"name": "Sam", "score": 88}
]

for s in students:
    print(s["name"], s["score"])
Tom 80 Jane 95 Sam 88
⚠️ 자주 헷갈리는 부분
주의 키 중복 불가 / d[k] vs get(k)
# 키 중복 → 나중 값으로 덮어씌움
d = {"a": 1, "a": 2}
print(d)        # {'a': 2}

# d["b"] → 오류,  d.get("b") → None
d2 = {"a": 1}
print(d2.get("b"))     # None (오류 없음)
print(d2.get("b", 0))   # 0 (기본값)
{'a': 2} None 0
