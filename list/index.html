08강 리스트(List) 인터랙티브 강의

직접 만지며 배우는 파이썬 리스트 — 인덱싱 · 슬라이싱 · 메서드 · 실전 예제 · 퀴즈
CONCEPT리스트(List)란?
여러 개의 값을 한 번에 저장하는, 순서가 있고 값을 바꿀 수 있는(mutable) 자료형입니다.

01리스트의 4가지 성질

① 여러 값을 한 번에 저장합니다 — 학생 점수 5개, 과일 이름 3개처럼 "묶음"으로 관리.

② 순서가 있습니다 — 인덱스(번호)로 값을 꺼낼 수 있습니다.

③ 인덱스는 0부터 시작합니다.

④ 값을 바꿀 수 있습니다(mutable) — 만든 뒤에도 수정·추가·삭제가 자유롭습니다.

02리스트 만들기 4가지

arr = [10, 20, 30]   # ① 대괄호로 만들기
arr = []             # ② 빈 리스트
arr = list()         # ③ list()로 만들기
arr = [0] * 5        # ④ 같은 값 N개 → [0, 0, 0, 0, 0]
INTERACTIVE · [0] * N 직접 만들어보기

SLICE인덱싱 · 슬라이싱 · 수정 · len
arr[start:end]는 start부터 end 직전까지! end는 포함되지 않는 것이 핵심입니다.

01기본 문법

arr = [10, 20, 30, 40, 50]
print(arr[0])    # 10  (인덱싱: 하나 꺼내기)
print(arr[-1])   # 50  (음수: 뒤에서 꺼내기)
print(arr[1:4])  # [20, 30, 40]  (슬라이싱: 구간 꺼내기)
print(arr[:3])   # [10, 20, 30]  (처음부터)
print(arr[2:])   # [30, 40, 50]  (끝까지)

02슬라이싱 시뮬레이터

LOOP리스트 반복 · 입력 패턴
세 가지 반복 방법을 한 단계씩 실행하며 눈으로 확인해 보세요.

01세 가지 반복 방법

# ① 값으로 반복
for x in arr:
    print(x)

# ② 인덱스로 반복
for i in range(len(arr)):
    print(i, arr[i])

# ③ enumerate() — 인덱스와 값을 동시에
for i, x in enumerate(arr):
    print(i, x)

03리스트 입력 패턴 (KOI 필수!)

# ① 한 줄에 숫자 여러 개 → 리스트
arr = list(map(int, input().split()))
# 입력: 1 2 3 4  →  arr = [1, 2, 3, 4]

# ② N개를 여러 줄로 입력받아 리스트로
n = int(input())
arr = []

    arr.append(int(input()))

02append vs extend — 가장 많이 틀리는 부분!

arr = [1, 2]
arr.append([3, 4])  # → [1, 2, [3, 4]]  리스트가 "한 덩어리"로!

arr = [1, 2]
arr.extend([3, 4])  # → [1, 2, 3, 4]    값이 "펼쳐져서"!
INTERACTIVE · 직접 비교하기 (arr = [1, 2]에서 시작)

03copy()와 연산 (+, *, in)

a = [1, 2, 3]
b = a.copy()       # 얕은 복사 — b를 바꿔도 a는 그대로
b.append(99)
print(a)  # [1, 2, 3]
print(b)  # [1, 2, 3, 99]

print([1, 2] + [3, 4])  # [1, 2, 3, 4]  (연결)
print([0] * 3)          # [0, 0, 0]     (반복)
print(20 in [10, 20, 30])  # True       (포함 검사)
