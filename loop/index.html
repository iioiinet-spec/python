04강 반복문(Loop) 인터랙티브 강의

한 단계씩 실행하며 배우는 for · while · break · continue · 중첩 반복문
FOR반복문 개념 · for 문 · range()
반복문은 같은 코드를 여러 번 반복해서 실행할 때 사용하는 문법입니다. for는 정해진 횟수, while은 조건이 참일 때 반복합니다.

01for 문 기본 구조

for 변수 in range(반복횟수):
    실행할 코드

for i in range(5):
    print(i)      # 0 1 2 3 4  ← 총 5번 반복!

range(5)는 0부터 4까지 만듭니다. 5는 포함되지 않는다는 것이 핵심!

02range() 시뮬레이터 — 세 가지 형태를 직접 실험!

range(n)              # 0부터 n-1까지
range(start, end)     # start부터 end-1까지
range(start, end, step) # step씩 건너뛰며
INTERACTIVE · range(start, end, step)

03for 문 기초 예제 — 1~10 합 구하기

sum = 0
for i in range(1, 11):
    sum += i
print(sum)   # 55
INTERACTIVE · 합 누적 과정 한 단계씩 보기 (1~10)
i = ?, sum = 0
「다음 단계」를 눌러 sum이 커지는 과정을 관찰하세요.
WHILEwhile 문 — 조건이 참인 동안 반복
while은 매 바퀴마다 조건을 검사합니다. 조건을 거짓으로 만드는 코드(i += 1)를 잊으면 무한 반복!

01while 문 기본 구조

while 조건:
    실행할 코드

i = 1
while i <= 5:
    print(i)
    i += 1       # 1 2 3 4 5

02while 스텝 실행기 — 조건 검사를 눈으로!

INTERACTIVE · i = 1 / while i <= 5
i = 1
버튼을 누르면 「조건 검사 → 실행 → i 증가」가 한 단계씩 진행됩니다.

03while 예제 — 1~10 합

i = 1
s = 0
while i <= 10:
    s += i
    i += 1
print(s)     # 55 — for와 결과가 같다!

같은 일을 for로도 while로도 할 수 있습니다. 횟수가 정해져 있으면 for, 조건 중심이면 while이 자연스럽습니다.

04반복문 + 조건문 — 짝수만 출력

for i in range(1, 11):
    if i % 2 == 0:
        print(i)    # 2 4 6 8 10
INTERACTIVE · 조건 필터 관찰기 — 배수를 바꿔보세요
CONTROLbreak · continue — 반복 흐름 제어
break는 반복문을 강제로 종료, continue는 현재 바퀴만 건너뛰고 다음 바퀴로 이동합니다.

01두 문법 비교

# break: i가 5가 되는 순간 반복 전체 종료
for i in range(10):
    if i == 5:
        break
    print(i)        # 0 1 2 3 4

# continue: i가 3일 때만 건너뛰고 계속
for i in range(1, 6):
    if i == 3:
        continue
    print(i)        # 1 2 4 5

02흐름 시각화기 — 한 바퀴씩 실행하며 색으로 확인

초록 테두리 = print 실행, 주황 취소선 = continue로 건너뜀, 빨강 = break로 종료, 흐림 = 아예 실행되지 않은 바퀴.

INTERACTIVE · 모드를 선택하고 단계 실행
「다음 바퀴」를 눌러 각 바퀴의 운명을 확인하세요.
NESTED중첩 반복문 · 별찍기 · 구구단
반복문 안에 반복문! 바깥 i가 한 번 돌 때 안쪽 j는 끝까지 돕니다.

01중첩 반복문 격자 실행기

for i in range(3):
    for j in range(3):
        print(i, j)   # 총 3 × 3 = 9번 실행
INTERACTIVE · (i, j)가 도는 순서를 격자로!
i가 0인 동안 j가 0→1→2로 먼저 다 돕니다.

02별찍기 실습기

for i in range(5):        # 일자 별찍기
    print("*")

for i in range(1, 6):     # 삼각형 별찍기
    print("*" * i)
INTERACTIVE · 줄 수와 모양을 바꿔보세요

03구구단 생성기

for i in range(1, 10):
    print("2 x", i, "=", 2 * i)
INTERACTIVE · 원하는 단을 출력해 보세요
PATTERN자주 쓰는 반복문 패턴 3가지
합 구하기 · 개수 세기 · 최댓값 찾기 — KOI/정올 문제의 뼈대가 되는 패턴입니다. 입력을 바꿔 실행해 보세요.

04리스트 반복 & enumerate

arr = [10, 20, 30, 40]
for x in arr:
    print(x)          # 10 20 30 40

arr = ["a", "b", "c"]
for i, v in enumerate(arr):
    print(i, v)       # 0 a / 1 b / 2 c

리스트를 다루는 자세한 내용은 08강 「리스트」에서 이어집니다.
