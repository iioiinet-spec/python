학습 포인트

      

        1. 역할 분담 — 바깥 for i가 한 번 돌 때마다 한 줄이 완성되고, 안쪽 for j는 그 줄의 칸을 채웁니다. print("*", end="")의 end=""가 자동 줄바꿈을 없애고, 안쪽 반복이 끝난 뒤 print() 한 번이 줄을 끝냅니다 — C의 printf("\n") 역할.

        2. range의 끝은 미포함! — range(1, n + 1)이 1~n을 도는 이유입니다. 역삼각형의 range(1, n - i + 2), 피라미드의 range(1, 2 * i)(별 2i-1개)도 같은 원리이고, 거꾸로 돌 때는 range(n - 1, 0, -1)처럼 음수 step을 씁니다.

        3. 공백도 문자다 — 오른쪽 정렬과 피라미드는 별보다 먼저 print(" ", end="")로 공백을 찍어 별을 밀어냅니다. 캔버스의 점선 칸이 바로 그 공백입니다.

        4. 파이썬다운 지름길 — print("*" * i) 문자열 곱하기 한 줄로도 같은 모양이 나옵니다! 중첩 반복문으로 원리를 이해했다면, 코드를 직접 이렇게 바꿔 실행해 보세요 (이 실습기에서 실제로 동작합니다).
