💡 판다스(Pandas)란?

판다스는 표 형태 데이터를 다루는 파이썬 라이브러리입니다.
엑셀처럼 행(row)과 열(column)로 데이터를 관리할 수 있습니다.

데이터 분석 · 통계 · AI · 웹 서비스에서 매우 많이 사용됩니다.

📊 Series — 1차원 데이터

📌 Series란?

Series는 한 줄의 데이터입니다. 리스트처럼 보이지만 인덱스(번호)가 자동으로 붙습니다.

기본 Series 만들기
import pandas as pd

s = pd.Series([10, 20, 30])
print(s)
0 10 1 20 2 30 dtype: int64
인덱스 인덱스 직접 지정
s = pd.Series([90, 85, 88],
               index=["민수", "지아", "철수"])
print(s)
print(s["민수"])
민수 90 지아 85 철수 88 dtype: int64 90
📋 DataFrame — 표 형태 데이터

📌 DataFrame이란?

DataFrame은 행(row)과 열(column)로 구성된 표입니다.
엑셀 시트처럼 생각하면 됩니다. 판다스에서 가장 중요한 자료형입니다.

생성 딕셔너리로 DataFrame 만들기
import pandas as pd

data = {
    "name":  ["민수", "지아", "철수"],
    "score": [90, 85, 88]
}

df = pd.DataFrame(data)
print(df)
name score 0 민수 90 1 지아 85 2 철수 88
🔍 데이터 확인 메서드
head() 앞부분 보기
df.head()      # 앞 5행
df.head(3)     # 앞 3행
info() 구조 정보
df.info()      # 열·타입·개수
df.describe()  # 요약 통계
🔧 데이터 조작
열 선택 특정 열만 가져오기
print(df["score"])        # 열 하나
print(df[["name", "score"]])  # 여러 열
조건 선택 조건에 맞는 행만 필터링
# 점수 85 초과인 학생만
print(df[df["score"] > 85])

# 90점 이상인 학생만
print(df[df["score"] >= 90])
name score 0 민수 90 2 철수 88
열 추가 새로운 열 만들기
df["grade"] = ["A", "B", "A"]
print(df)
name score grade 0 민수 90 A 1 지아 85 B 2 철수 88 A
정렬 sort_values()
# 오름차순 (기본)
df.sort_values("score")

# 내림차순
df.sort_values("score", ascending=False)
통계 mean · sum · max · min
print(df["score"].mean())   # 87.67
print(df["score"].sum())    # 263
print(df["score"].max())    # 90
print(df["score"].min())    # 85
CSV 파일 읽기·저장
# CSV 읽기
df = pd.read_csv("data.csv")

# CSV 저장
df.to_csv("new_data.csv", index=False)

📝 실전 예제
예제 1 학생 점수 분석
import pandas as pd

data = {
    "name":  ["민수", "지아", "철수", "영희"],
    "score": [90, 85, 88, 92]
}
df = pd.DataFrame(data)

print("데이터")
print(df)
print("평균:", df["score"].mean())
print("최고점:", df["score"].max())
print("최저점:", df["score"].min())
데이터 name score 0 민수 90 1 지아 85 2 철수 88 3 영희 92 평균: 88.75 최고점: 92 최저점: 85
예제 2 조건 필터링
import pandas as pd

data = {
    "name":  ["민수", "지아", "철수", "영희"],
    "score": [90, 85, 88, 92]
}
df = pd.DataFrame(data)

high = df[df["score"] >= 90]
print("90점 이상 학생")
print(high)
90점 이상 학생 name score 0 민수 90 3 영희 92
예제 3 열 추가 + 정렬
import pandas as pd

data = {
    "name":  ["민수", "지아", "철수"],
    "score": [90, 85, 88]
}
df = pd.DataFrame(data)

df["grade"] = ["A", "B", "B"]
df = df.sort_values("score", ascending=False)

print(df)
name score grade 0 민수 90 A 2 철수 88 B 1 지아 85 B
