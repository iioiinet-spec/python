리스트란?

리스트는 여러 개의 값을 한 번에 저장하는 자료형입니다.
학생 점수 5개, 과일 이름 3개처럼 "묶음"으로 관리할 때 사용합니다.

✅ 순서가 있고  |  ✅ 인덱스로 접근 가능  |  ✅ 값 변경 가능(mutable)

🔬 리스트 구조 시각화
셀을 클릭하면 인덱스 정보를 볼 수 있습니다
👆 셀을 클릭해보세요
📋 리스트 특징 정리
특징설명예시
순서 있음저장 순서를 기억함[10, 20, 30] 순서 유지
인덱스0부터 시작하는 번호arr[0] → 첫 번째 값
가변(mutable)값 변경·추가·삭제 가능arr[1] = 99
중복 허용같은 값 여러 개 저장 가능[1, 2, 2, 3]
혼합 타입다양한 자료형 함께 저장[1, "hello", 3.14]
🛠️ 리스트 만들기
방법 1 대괄호로 만들기
arr = [10, 20, 30]
print(arr)
[10, 20, 30]
방법 2 빈 리스트
arr = []
arr2 = list()
print(arr, arr2)
[] []
방법 3 같은 값 N개
arr = [0] * 5
print(arr)
[0, 0, 0, 0, 0]
방법 4 입력으로 만들기
arr = list(map(int, input().split()))
print(arr)
입력: 1 2 3 4 → [1, 2, 3, 4]
🎯 인덱싱 (Indexing)

📌 인덱스 규칙

인덱스는 0부터 시작합니다. 음수 인덱스는 뒤에서부터 셉니다.

양수 앞에서 인덱싱
arr = [10, 20, 30, 40]
print(arr[0])  # 10
print(arr[2])  # 30
10 30
음수 뒤에서 인덱싱
arr = [10, 20, 30, 40]
print(arr[-1])  # 40
print(arr[-2])  # 30
40 30
✂️ 슬라이싱 (Slicing)

📌 슬라이싱

arr[start:end] 형태로 구간을 잘라냅니다. end는 포함되지 않습니다.

슬라이싱 다양한 예제
arr = [10, 20, 30, 40, 50]

print(arr[1:4])   # [20, 30, 40]
print(arr[:3])    # [10, 20, 30]
print(arr[2:])    # [30, 40, 50]
[20, 30, 40] [10, 20, 30] [30, 40, 50]
✏️ 값 바꾸기 & len()
수정 값 바꾸기
arr = [10, 20, 30]
arr[1] = 999
print(arr)
[10, 999, 30]
len 길이 구하기
arr = [1, 2, 3, 4]
print(len(arr))
4
🔁 리스트 반복문
방법 1 값으로 반복 (for x in arr)
arr = [10, 20, 30]
for x in arr:
    print(x)
10 20 30
방법 2 인덱스로 반복 (range + len)
arr = [10, 20, 30]
for i in range(len(arr)):
    print(i, arr[i])
0 10 1 20 2 30
방법 3 enumerate() — 인덱스+값 동시에
arr = [10, 20, 30]
for i, x in enumerate(arr):
    print(i, x)
0 10 1 20 2 30
📥 리스트 입력 받기
입력 1 한 줄에 여러 숫자
arr = list(map(int, input().split()))
print(arr)
입력: 1 2 3 4 → [1, 2, 3, 4]
입력 2 N개 줄로 입력
n = int(input())
arr = []
for _ in range(n):
    arr.append(int(input()))
입력 3개씩 → [a, b, c]
⚙️ 리스트 메서드 모음
append(x) 맨 뒤에 추가
arr = [1, 2]
arr.append(3)
print(arr)
[1, 2, 3]
insert(i,x) 위치에 끼우기
arr = [1, 2, 3]
arr.insert(1, 99)
print(arr)
[1, 99, 2, 3]
extend() 여러 개 붙이기
arr = [1, 2]
arr.extend([3, 4, 5])
print(arr)
[1, 2, 3, 4, 5]
append([3,4]) → [1,2,[3,4]] (덩어리)
extend([3,4]) → [1,2,3,4] (펼쳐짐)
pop() 꺼내기(삭제+반환)
arr = [10, 20, 30]
x = arr.pop()     # 맨 뒤
print(x, arr)
y = arr.pop(0)   # 0번 인덱스
print(y, arr)
30 [10, 20] 10 [20]
remove(x) 값으로 삭제
arr = [1, 2, 2, 3]
arr.remove(2)   # 첫 번째만 삭제
print(arr)
[1, 2, 3]
sort() 정렬
arr = [3, 1, 2]
arr.sort()
print(arr)          # 오름차순
arr.sort(reverse=True)
print(arr)          # 내림차순
[1, 2, 3] [3, 2, 1]
reverse() 뒤집기
arr = [1, 2, 3]
arr.reverse()
print(arr)
[3, 2, 1]
index / count 찾기·세기
arr = [1, 2, 2, 2, 3]
print(arr.index(2))   # 1
print(arr.count(2))   # 3
1 3
clear / copy 삭제·복사
a = [1, 2, 3]
b = a.copy()
b.append(99)
print(a)  # 원본 변화 없음
print(b)
[1, 2, 3] [1, 2, 3, 99]

🏆 실전 예제 모음
예제 1 최댓값 구하기
arr = list(map(int, input().split()))

mx = arr[0]
for x in arr:
    if x > mx:
        mx = x

print(mx)
입력: 3 7 1 9 2 → 9
예제 2 짝수만 모으기
arr = list(map(int, input().split()))
even = []

for x in arr:
    if x % 2 == 0:
        even.append(x)

print(even)
입력: 1 2 3 4 5 6 → [2, 4, 6]
예제 3 중복 제거
arr = list(map(int, input().split()))
uniq = []

for x in arr:
    if x not in uniq:
        uniq.append(x)

print(uniq)
입력: 1 2 2 3 3 3 → [1, 2, 3]
예제 4 정렬 후 가장 큰 2개 합
arr = list(map(int, input().split()))
arr.sort()
print(arr[-1] + arr[-2])
입력: 3 1 4 1 5 → 9
예제 5 특정 값 개수와 위치
arr = list(map(int, input().split()))
x = int(input())

print(arr.count(x))
if x in arr:
    print(arr.index(x))
else:
    print(-1)
입력: 1 2 2 3 / x=2 → count:2, index:1
