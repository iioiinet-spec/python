02강 조건문(if) 인터랙티브 강의

if · else · elif · 비교/논리 연산자 · 중첩 · 삼항 — 그리고 연습문제 19제
IF조건문 — 참일 때만 실행!
조건문은 어떤 조건이 참(True)일 때만 실행되는 문장입니다.

01if 문 기본 구조

if 조건:
    실행할 코드

age = 15
if age >= 14:
    print("중학생입니다")   # age가 14 이상이므로 실행!

02if 판정기 — 조건의 참/거짓을 눈으로!

n = int(input())
if n > 0:
    print("양수입니다")
INTERACTIVE · n 값을 바꿔 조건 검사 결과 보기

03if - else — 참이면 if, 거짓이면 else!

n = int(input())
if n % 2 == 0:
    print("짝수")
else:
    print("홀수")
INTERACTIVE · 두 갈래 중 어느 길로 갈까?
ELIFif - elif - else 사다리
여러 조건을 위에서부터 순서대로 검사하다가, 처음으로 참이 되는 곳 하나만 실행됩니다!

01성적 판정 시뮬레이터

score = int(input())
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")
INTERACTIVE · 점수를 바꿔 검사 순서 관찰하기

경계값(90점, 80점)을 꼭 넣어보세요. >= 이므로 90점은 A입니다!

OPERATOR비교 연산자 · 논리 연산자
조건문의 재료가 되는 연산자들입니다. 결과는 항상 True 아니면 False!

01비교 연산자 실험기 — 6개를 한 번에!

INTERACTIVE · a, b 값을 바꾸면 표가 즉시 갱신됩니다
연산자의미식결과

02논리 연산자 — and · or · not

age = 15
if age >= 14 and age <= 16:
    print("중학생")     # 두 조건이 모두 참이어야 실행!
INTERACTIVE · age를 바꿔 and 조건 분해 보기

03진리표 — and / or / not

INTERACTIVE · 연산자를 골라 진리표 확인
DEEP중첩 if · 삼항 연산
조건문 안에 조건문을 넣거나, if-else를 한 줄로 줄여 쓸 수 있습니다.

01중첩 if — 2단계 관문 통과하기

n = int(input())
if n > 0:
    if n % 2 == 0:
        print("양수 짝수")   # 두 관문을 모두 통과해야 출력!
INTERACTIVE · n이 두 관문을 통과하는지 확인

02삼항 연산 — if-else를 한 줄로!

n = int(input())
print("짝수" if n % 2 == 0 else "홀수")

# 구조:  참일_때_값  if  조건  else  거짓일_때_값
